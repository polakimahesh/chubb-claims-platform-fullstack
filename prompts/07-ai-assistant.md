# 07 - AI assistant that raises and decides claims

Prompts used (verbatim, in order):

1. "create a one agent to raise a claim and one agent should accept or reject a claim is it possible no need human interaction here"
2. "now in UI create a claim means agent should create a claim"
3. "do the changes simply"
4. "I have one question you have done the changes in agentcontroller right just you kept agent but actually i want AI agent what i'll ask it should do the changes right"
5. "I want AI agent not code level agent"

Note: prompt 3 first produced a browser-only "random claim" button. That was not an AI agent and was removed after
prompt 4, which is when the real assistant was built.
